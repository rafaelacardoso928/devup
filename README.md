# devup
# 🚀 DEVUP - Landing Page Curso de Desenvolvimento

Projeto de Landing Page moderna para curso de programação, desenvolvido utilizando apenas tecnologias nativas da web.

---

## 📌 Sobre o Projeto

A **DEVUP** é uma landing page criada para divulgar um curso completo de desenvolvimento web.  
O projeto foi desenvolvido com foco em:

- Estrutura semântica
- Responsividade
- Animações modernas
- Slider manual e automático
- Manipulação de DOM com JavaScript puro

---

## 🎯 Objetivo do Desafio

Criar um **slider/carrossel de imagens funcional**, utilizando exclusivamente:

- ✅ JavaScript puro
- ✅ Manipulação de DOM
- ✅ EventListener
- ✅ Estruturas condicionais
- ✅ Array

⚠ Não foi utilizado:

- Bootstrap
- Swiper
- Slick
- Bibliotecas prontas
- Frameworks externos

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 📸 Funcionalidades

### 🔹 Menu Responsivo
- Menu desktop alinhado à direita
- Menu hambúrguer exibido apenas em telas menores
- Animação de abertura suave

### 🔹 Hero Section
- Fundo com gradiente animado
- Botão com efeito hover

### 🔹 Grade do Curso
- Layout em Grid
- Cards com microinterações

### 🔹 Slider / Carrossel
- Navegação manual (botões anterior/próximo)
- Troca automática a cada 4 segundos
- Transição suave (fade)
- Implementado com:
  - querySelectorAll
  - Array.from()
  - classList
  - setInterval()
  - Condicionais ternárias

### 🔹 Animação Reveal
- Elementos aparecem ao rolar a página
- Utilização de getBoundingClientRect()

### 🔹 Botão Voltar ao Topo
- Aparece ao rolar a página
- Scroll suave até o topo

### 🔹 Botão WhatsApp Flutuante
- Link direto para contato

### 🔹 Formulário
- Validação básica
- Mensagem de confirmação ao enviar
